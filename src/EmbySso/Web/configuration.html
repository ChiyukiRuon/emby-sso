Rauthy SSO

使用标准 OIDC 登录。管理员和普通用户都可以绑定 SSO；新账号默认没有媒体库访问权限。

启用后 PublicUrl、Issuer 和 OIDC 端点可以使用 http://。授权码、Token 和 Emby AccessToken 会明文传输；Rauthy 客户端也必须允许 http Redirect URI。生产环境请保持关闭。
通常使用 HTTPS；启用上面的不安全 HTTP 选项后也可以使用 http://。包含反向代理的路径前缀，不含 /web。客户端 PIN 码页面为此地址后加 /sso。
必须与发现文档中的 issuer 完全一致，包括末尾斜杠。Rauthy 客户端的 ID Token Algorithm 使用 RS256、RS384 或 RS512（建议 RS256），不支持 EdDSA。
Rauthy 可留空，默认使用 Issuer 所在域名的 /.well-known/openid-configuration。
留空表示允许这个 Rauthy 客户端的全部成功认证用户。
留空则没有媒体库权限。仅影响新账号，既有账号的权限不变。可从 Emby 媒体库管理页面的地址或 API 获取 ID。
