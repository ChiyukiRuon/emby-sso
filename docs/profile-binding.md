# 在个人配置页管理 SSO

登录 Emby Web 后，打开个人设置中的个人配置页，在密码设置下方找到“SSO 账号绑定”。此区域沿用 Emby 原生输入框、按钮、分组和主题。

- 未绑定：输入 Emby 本地密码，点击“绑定 SSO 账号”，完成身份提供商授权后返回个人配置页。
- 已绑定：输入 Emby 本地密码，点击“解除 SSO 绑定”，成功后在原页显示结果，不退出当前 Emby 会话。
- 用户名自动取自服务端验证过的登录会话，无需填写，也不能指定其他账号。
- 通过 SSO 自动创建的用户，请先在上方密码设置中设置本地密码。
- 新版插件通过 SSO 自动创建账号后，会在登录后的页面弹出“请修改本地密码”；点击“确认”进入个人配置页。未修改前，刷新、重新打开页面或进入其他页面会再次提醒；确认后的跳转不会连续弹窗。
- 服务端根据实际密码变化停止提醒，点击确认或关闭提示不算完成修改。修改成功后，其他浏览器再次打开页面也不会提醒；管理员重置密码同样会被识别。
- 旧版绑定数据没有记录账号来源及初始密码指纹，无法可靠判断是否需要提醒，因此旧账号不自动补弹。绑定已有 Emby 账号也不会触发提醒。
- 密码错误会在表单内提示，清空密码后可以重新输入并重试。

独立的 `/sso` 页面仅用于登录，不再提供绑定或解绑表单。更新插件 DLL 并重启 Emby 后，刷新浏览器页面以加载新脚本。

Emby 登录页的“使用 SSO 登录”按钮会直接跳转身份提供商，无需再在 `/sso` 页面点击一次。按钮会在后台获取一次性 CSRF 票据，然后提交授权请求；直接访问 `/sso` 仍可使用原有登录入口。
